# e-Library and Student Learning Hub — Editable Word Interfaces

## Urgent e-Library deliverable — 21 interfaces

[Download e_Library_System_21_Editable_Word_Interfaces.docx](./e_Library_System_21_Editable_Word_Interfaces.docx)

This document contains exactly 21 e-Library interfaces derived from the supplied Context Diagram, DFD, FDD and assignment report. It uses 1,661 native Microsoft Word shapes, Calibri, A4 portrait, fully editable fields, buttons, popups, process cards and output panels. There are no embedded PNG or image files and no page numbers. The cover contains a redesigned project card and four-column Team Directory with the three submitted group members.

Generated by `generate_elibrary_21_word_shapes.py`.

## New: 22 interfaces, different layout, no page numbers

[Download Student_Learning_Hub_22_Interface_Blueprint.docx](./Student_Learning_Hub_22_Interface_Blueprint.docx)

- 22 interfaces, one full window mockup per page
- Numbered callouts 1 to 5 on the mockup, explained in an element note grid below it
- Horizontal top navigation, popup dialog floating over the screen, dashed processing strip
- A4 portrait, Calibri, fully English, **no page numbers anywhere**
- 16 different screen layouts (form, dashboard, grid, table, calendar, quiz, upload, result and more)

Screens: Login, Student Registration, Forgot Password, Student Dashboard, Student Profile,
Account Settings, Course Catalogue, Course Details, Course Enrolment, Learning Module Viewer,
Learning Materials, Class Timetable, Assignment List, Assignment Details, Assignment Submission,
Assignment Results, Quiz List, Quiz Attempt, Quiz Results, Discussion Forum,
Notification Centre, Log Out Confirmation.

Generated by `generate_22_interfaces_doc.py`. `check_22_layout.py` verifies that no shape
falls outside the page, no wording overlaps and nothing is hidden behind the popup dialog.
`preview_22_pages.py` renders throwaway PNG previews for checking only.
